# URL Async Checker Service

Сервис для асинхронной пакетной проверки доступности списка URL-адресов с ограничением параллельности, случайной задержкой, измерением времени ответа и мониторингом статуса в реальном времени.

## Стек технологий

- **Backend:** Node.js, NestJS, TypeScript, In-Memory Storage, Jest
- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS, Zustand, Lucide Icons, Vitest
- **Shared:** Общий пакет TypeScript типов и DTO (`@url-checker/shared`)
- **DevOps:** Docker, Docker Compose, Nginx, Multi-stage builds

---

## Архитектура и особенности

1. **Ограничение параллельности (Concurrency Pool):**
   - Не более 5 одновременных HTTP HEAD-запросов на одно задание.
   - Независимая параллельная обработка нескольких заданий.
2. **Искусственная задержка:**
   - Случайная задержка 0–10 секунд перед сохранением результата каждой ссылки (согласно ТЗ).
3. **Отмена заданий (`DELETE /api/jobs/:id`):**
   - Прекращение обработки неначатых URL и перевод их в статус `cancelled`.
4. **Периодический опрос (Polling) с защитой от Race Conditions:**
   - Автоматический опрос активного задания каждые 1.5 сек.
   - Корректная остановка опроса при переключении задания.
   - Защита от применения устаревших ответов к текущему состоянию.
5. **Тестирование:**
   - Unit-тесты сервисов бэкенда на Jest.
   - Unit-тесты компонентов фронтенда на Vitest + Testing Library.

## Запуск через Docker Compose (Рекомендуемый)

Убедитесь, что у вас установлены [Docker](https://www.docker.com/) и [Docker Compose](https://docs.docker.com/compose/).

```bash
# Сборка и запуск контейнеров
docker-compose up --build

  - Frontend UI: http://localhost:3000
  - Backend API: http://localhost:4000/api
```

Для остановки контейнеров:
```bash
docker-compose down
```
Локальный запуск (Development)

Требования: Node.js >= 20.0.0, npm >= 9.0.0.

1. Установка зависимостей и сборка общих типов
```bash
npm install
npm run build:shared
```
2. Запуск сервисов

В отдельных терминалах:
```bash
# Терминал 1: Запуск бэкенда (порт 4000)
npm run dev:backend

# Терминал 2: Запуск фронтенда (порт 3000)
npm run dev:frontend
```
Запуск тестов
```bash
# Запуск всех тестов (бэкенд Jest + фронтенд Vitest)
npm run test:all

# Тесты только бэкенда
npm run test

# Тесты только фронтенда
npm run test:frontend
```
REST API Эндпоинты

| Метод    | Эндпоинт        | Описание                                                           |
| :------- | :-------------- | :----------------------------------------------------------------- |
| `POST`   | `/api/jobs`     | Создание задания на проверку URL (принимает `{ "urls": ["..."] }`) |
| `GET`    | `/api/jobs`     | Получение списка всех заданий с краткой статистикой                |
| `GET`    | `/api/jobs/:id` | Детальная информация по заданию и всем входящим в него URL         |
| `DELETE` | `/api/jobs/:id` | Отмена выполнения задания и остановка неначатых URL                |
